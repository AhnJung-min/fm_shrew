# 플러그인 릴리스 점검표

플러그인(C#)에는 자동 테스트가 없어서, 올릴 때마다 켜진 게임에서 아래를 한 번 확인한다. 앱 쪽 계약(응답 모양)은 `npm test`의 `tests/pluginContract.test.ts`가 본다.
시험은 시험용 세이브로 한다. 에디터 시험은 게임 메모리만 고치므로, 끝나면 세이브하지 말고 게임을 끈다.

## 준비

- [ ] 새 `FmBojwagwan.dll`을 게임 폴더에 넣고, FM을 **완전히 껐다가** 다시 켠다(켤 때 읽은 파일을 계속 쓴다).
- [ ] 앱을 켠다. 왼쪽 아래에 "FM 연결됨(팀 이름)"이 보이고, 대시보드 구단 재정·건강 카드가 채워진다.
- [ ] 플러그인 버전과 앱이 기대하는 버전(`src/shared/pluginGates.ts`의 버전 문 표)이 맞다. `/ping`이 새 버전을 돌려준다.
- [ ] 일반 배포본이면 개발용 창구(`/props` 등)가 "unknown path"로 거절된다. 우리 게임 폴더에는 개발 빌드(`-p:DevEndpoints=true`)를 넣는다.

## 직접 답변 칸

- [ ] 기자회견, 면담, 팀 대화 화면의 선택지 아래에 "직접 답변" 칸이 뜬다.
- [ ] 말을 적고 [말하기]를 누르면 상대의 반응과 "적용할 선택지"가 칸에 뜬다(앱이 켜져 있고 API 키가 있을 때).
- [ ] [반영하고 넘어가기]를 **누르기 전에는** 게임에 아무것도 적용되지 않는다. 누르면 그 선택지가 적용된다.
- [ ] 경기 중 외침 메뉴를 열면 왼쪽 위에 칸이 있고, 처음엔 접혀 있다. [외치기]를 눌러야 적용된다.
- [ ] 앱을 끄고 말하면 45초 뒤 "앱을 켜면 쓸 수 있습니다"가 뜬다. API 키가 없으면 "Claude API 키가 없습니다" 안내가 칸에 뜬다.
- [ ] 칸에 글을 쓰는 동안 게임 단축키가 꺼져 있다.

## 에디터 "게임에 반영"

- [ ] 앱 에디터에서 선수 한 명의 능력치 하나를 고치고 "게임에 반영"을 누르면 확인창이 먼저 뜬다.
- [ ] 반영한 뒤 게임의 그 선수 화면에서 값이 같다.
- [ ] 범위 밖 값(숙련 1~20, 능력치 1~20, 현재·잠재 능력 1~200)이나 현재 능력이 잠재 능력보다 큰 값은 거절된다.
- [ ] 고친 값은 다른 화면에 다녀와도 남아 있고, 에디터 메뉴에 "고침 N"이 붙는다. 반영 뒤 선수·항목마다 들어간 것이 보인다.
- [ ] 시험한 값은 원래 값으로 다시 반영해 되돌린다(`/live/player`로 처음 값과 같은지 본다).
- 쓰기 도중의 실패는 일부러 만들 수 없다(범위 밖 값은 쓰기 전에 거절된다). 되돌리기는 플러그인 코드와 앱의 반영 결과 표시(`tests/editorReport.test.ts`)로만 확인한다.

## 경기 평점 기록(0.13.0부터)

- [ ] 세이브를 불러오고 1분쯤 지나면 `%LOCALAPPDATA%\FmBojwagwan\records\ratings.jsonl`에 직전 경기 한 줄이 생긴다(BepInEx 기록에 "ratings: recorded").
- [ ] 줄의 `myTeamId`가 앱의 내 팀 번호와 같고, 팀마다 뛴 시간의 합이 경기 길이 × 11이다.
- [ ] 앱을 켜면 설정의 "기록"에 그 세이브의 평점 경기 수가 1 늘어 있다.

## 경기 카드

- [ ] 골이 들어가면 오른쪽 위에 득점자, 도움, 시간, 이번 경기 몇 호 골이 나오고 9초 뒤 사라진다(순위표가 있으면 14초).
- [ ] 멀티골, 해트트릭, 자책골은 제목이 따로 나온다. 비디오 판독 뒤 도움 없는 골은 "페널티킥"으로 나온다.
- [ ] 경기가 끝나면 최우수 선수 카드가 15초 뜬다.

## 화면 기록

- [ ] F10을 누르면 `dumps` 폴더에 화면 기록이 새로 생긴다.
- [ ] 게임을 다시 켜면 기록이 최근 150개만 남는다.

## 버전 안내

- [ ] 옛 플러그인(0.9.0 등)이 올라가 있을 때 앱 왼쪽 아래에 "FM을 다시 켜야 합니다(플러그인 옛 버전)"가 뜨고, 새 기능(몸값·주급, 구단·건강 카드)은 꺼진 채 나머지는 동작한다.
- [ ] 안내 문구의 버전 숫자가 지금 기대하는 버전과 같다.
- [ ] FM을 완전히 껐다 켜면 안내가 사라진다.

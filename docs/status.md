# FM 보좌관 개발 현황

2026년 11월 27일에 저장소의 파일(`src/`, `plugin/`, `tests/`, `docs/`)을 읽고 정리했고, 수식 검토 5회차 반영(11월 28일)에 맞춰 5장과 11장을 고쳤다. 만들어 온 과정이 아니라 **지금 코드가 하는 일**을 적는다. 이 문서와 코드가 다르면 코드가 맞다.

더 자세한 문서:

- 점수 계산식: [`scoring.md`](scoring.md)
- 화면 디자인 규칙: [`design.md`](design.md)
- 설치와 실행: [`README.md`](../README.md)

## 1. 한눈에 보기

| 항목 | 내용 |
|---|---|
| 무엇 | Football Manager 26 옆에 띄워 두는 Windows 보조 앱과, 게임 안에서 도는 플러그인 |
| 앱 | Electron 45, React 19, TypeScript. 화면은 한국어이고 글꼴은 Pretendard |
| 플러그인 | BepInEx 6(IL2CPP)용 C# 플러그인, 버전 0.12.0 |
| 자료 | 세이브 파일(.fm)을 직접 풀어서 **읽기만** 한다. FM이 켜져 있으면 플러그인을 거쳐 게임의 지금 값으로 덮어쓴다 |
| 둘의 연결 | 플러그인이 이 PC 안에서만 닿는 주소(127.0.0.1)에 작은 서버를 연다. 요청마다 암호(토큰)를 확인한다 |
| 코드 양 | 앱 16,900줄(화면 6,600, 계산 5,600, 앱 본체 4,700), 화면 스타일 4,900줄, 플러그인 6,400줄, 테스트 4,600줄 |
| 검사 | 테스트 20개 파일, 430개(429개 통과, 1개 건너뜀) |

## 2. 쓰는 흐름

1. **앱을 켠다.**
   - 한 번에 하나만 뜬다.
   - 3초마다 FM이 켜져 있는지 확인한다.
2. **시작 화면에서 세이브를 골라 적용한다.**
   - 세이브에 든 모든 선수(약 10만 명)와 구단, 계약, 경기 일정, 리그 순위표를 읽는다.
   - 마지막에 적용한 세이브는 다음에 앱을 켤 때 다시 적용된다.
3. **대시보드로 넘어간다.** 앱을 켠 지 20초 안에 세이브가 적용되면 저절로 넘어간다. 그사이 사용자가 다른 화면을 골랐으면 넘어가지 않는다.
4. **FM에서 같은 세이브로 감독에 들어가면** 게임의 지금 값을 받아 세이브 값 위에 덮어쓴다. 받는 값은 능력치, 현재·잠재 능력, 포지션 숙련이다. 다시 받는 때는 다음과 같다.
   - 3분이 지났을 때
   - 게임이 세이브를 저장했을 때
   - 시작 화면에서 "게임에서 값 다시 받기"를 눌렀을 때
5. **창을 닫아도** 알림 영역에 남는다. 그래서 게임 안 직접 답변과 백업이 계속 돈다. 설정에서 끌 수 있다.

왼쪽 메뉴 아래 상태 줄이 지금 상태를 알려 준다.

- FM: 꺼져 있음 / 연결됨(팀 이름) / 다시 켜야 함(플러그인이 옛 버전)
- 능력치: 게임의 지금 값을 쓰는 중 / 세이브에 저장된 값을 쓰는 중

## 3. 화면별 기능

메뉴 순서는 대시보드, 시작, 스쿼드, 영입 후보, 선수 비교, 에디터, 백업, 설정이다. 화면 코드는 `src/renderer/src/screens/`에 있다.

### 대시보드

구단 현황과 할 일을 카드로 모았다. 카드마다 어느 자료를 썼는지 적는다. 세이브의 날짜이거나, 게임 값을 받은 시각이다.

| 카드 | 보여 주는 것 |
|---|---|
| 오늘의 브리핑 | 최대 5줄. 줄마다 좋음·주의·위험·참고 표시 |
| 영입 추천 | 보강이 가장 급한 자리의 즉시 전력 후보 3명. 추천 점수, 등급, 소속, 현재·잠재 능력, 주전과의 차이 |
| 계약 만료 예정 | 1년 이내와 1~2년 목록(각 10명까지), 이미 끝난 선수, 1년 안에 끝나는 계약의 주급 합계 |
| 구단 재정·시설·건강 | 구단 프로필, 시설, 재정, 선수단 건강(부상, 징계, 컨디션, 경기 감각, 사기, 평점). FM이 켜져 있을 때만 보이고 3분마다 새로 읽는다 |
| 선수단 현황 | 1군 인원, 임대로 들어오고 나간 선수, 팀별 인원과 평균 나이 |
| 연령 구조 | 나이 4구간 막대. 구간을 누르면 선수 목록이 펼쳐진다 |
| 경기 센터 | 지난 5경기와 다음 5경기, 리그 순위표(세이브에 저장된 시점) |
| 정리 후보 TOP 5 | 전술에 자리가 없거나, 주급이 높거나, 나이에 비해 성장이 멈춘 선수. 30점 이상만 보인다. "임대 보내 키울 선수" 목록도 있다 |
| 주급 과다 의심 TOP 5 | 같은 리그에서 능력과 나이가 비슷한 선수의 기대 주급보다 몇 배를 받는지. 심하면 "강한 의심" 표시 |

선수 이름을 누르면 오른쪽에 선수 정보 창이 열린다.

### 시작

세 단계 카드다.

1. **FM 켜기**: 연결 상태와 플러그인 버전을 보여 준다. 옛 플러그인이면 앱이 기능마다 요구하는 버전(`shared/pluginGates.ts`의 표, 숫자를 따로 적지 않는다)을 모두 적고 플러그인을 바꾼 뒤 FM을 완전히 껐다 켜라고 안내한다. 일부 기능만 꺼진 버전이면 꺼진 기능을 한 줄로 알린다.
2. **세이브 고르기**: 세이브 목록(저장 시각, 크기)에서 골라 적용하거나 다시 읽는다.
3. **자료 쓰기**: 읽은 선수 수, 내 팀, 능력치 출처를 보여 준다. 대시보드·스쿼드·영입 후보·에디터로 가는 바로가기가 있다.
   - **내 구단 고르기**: 내 팀을 모르는 세이브(FM이 꺼져 있어도)에서는 세이브의 구단 목록이 나온다. 이름·나라로 찾고, 1군 선수 수와 체급(상위 22명 평균 현재 능력)이 보인다. 세이브 요약(`save_game_summary`)에 감독이 맡은 구단으로 적힌 곳이 맨 앞에 "게임에서 맡았던 구단"으로 나온다. 고르면 그 세이브의 내 팀으로 기억하고 대시보드로 간다. "다시 고르기"로 언제든 바꿀 수 있다.
   - **게임이 이긴다**: FM이 켜져 있고 게임의 내 팀 선수 이름이 이 세이브의 다른 팀과 겹치면, 게임이 알려 준 구단으로 바꾸고 한 줄로 알린다.
   - **세이브 형식 점검**: 세이브를 읽은 직후 형식 점검(아래 6장)에 걸리면 무엇이 이상한지를 보여 주고 점수 화면을 막는다.

### 스쿼드

내 팀 선수를 세 가지로 본다.

- **표**
  - 정렬과 검색을 한다.
  - 열 묶음을 켜고 끈다. 골키퍼 능력치와 계약은 처음에 꺼 둔다.
  - 최적 역할과 적합도 열이 있다.
  - 능력치는 네 단계 색 칩으로 보인다.
  - 줄 간격은 "촘촘하게/넉넉하게"로 바꾼다.
  - 게임 화면에 보이는 능력치만 넣는다.
- **전술판**
  - 포메이션을 고르고 자리마다 역할을 고른다.
  - 자리마다 주전, 후보, 적합도, 보강 필요도가 보인다.
  - 옆의 전술 분석 패널에는 다음이 있다.
    - 줄별 요약(골키퍼, 수비, 미드필드, 공격)
    - 보강이 급한 자리 순서
    - 자리마다 풀이: 주전 전력, 후보 두께, 주전 나이, 주전 계약
    - "이 자리 영입 후보 보기" 버튼
- **뎁스 차트**: 포메이션 모양대로 자리마다 주전과 후보 2명을 보여 준다.

"선수단 진단"을 켜면 나이 구성, 성장 기대주, 핵심 전력, 계약 만료 임박 같은 카드가 나온다. 선수를 누르면 선수 정보 창이 열리고, 여기서 선수 비교에 담을 수 있다.

### 영입 후보

세이브에 든 모든 구단의 선수를 고른 자리의 점수로 줄 세운다. 위에서 300명까지 보여 준다.

- **보강할 자리**
  - 전술 분석의 자리 묶음을 보강 필요도 순으로 늘어놓는다.
  - 가장 급한 자리를 먼저 고른다.
  - "직접 고르기"를 누르면 전술과 상관없이 아무 역할이나 고른다.
- **유형 탭**: 전체, 즉시 전력, 로테이션 자원, 유망주(23세 이하), 자유 계약. 탭마다 인원수가 붙는다.
- **거르기**
  - 나이 상한
  - 이름 검색
  - 이 자리를 뛸 수 있는 선수만(기본으로 켜 둠)
  - 구단을 모르는 선수도
  - 계약 1년 이내만
- **표의 열**
  - 추천 점수와 등급, 유형, 적합도, 주전 대비
  - 나이, 포지션, 소속(임대 중이면 원래 구단도)
  - 몸값, 주급, 계약 만료, 입지, 국적
  - 현재·잠재 능력, 모든 능력치
- **등급**
  - 강력 추천, 추천, 고려, 보류가 있다.
  - 영입 현실성이 낮은 선수는 "고려"까지만 준다. 주급이 내 팀 최고의 1.3배 이상인 선수가 그런 예다.
- **점수 풀이**: 선수마다 항목별 점수와 경고, 그 탭의 가중치 표를 펼쳐 본다.
- **몸값·주급**
  - FM이 켜져 있으면 보이는 선수를 30명씩 게임에 묻는다. 게임이 보여 주는 금액(스카우트 정도에 따른 범위)으로 바꾼다.
  - 꺼져 있으면 세이브 값을 원화로 바꿔 보여 준다.
- **그 밖**
  - 게임이 여자 선수라고 알려 준 줄은 뺀다.
  - 선수 정보 창에서 "에디터에서 열기"를 누를 수 있다.

### 선수 비교

내 팀 선수를 3명까지 나란히 본다.

- **레이더 그림**: 필드 선수 축이다. 모두 골키퍼면 골키퍼 축이다.
- **능력치 표**: 묶음별로 보이고, 가장 높은 값에 표시가 붙는다.
- **역할**: 선수마다 최적 역할과 점수가 나온다.

### 에디터

선수의 값을 고쳐 **켜져 있는 게임에 바로** 넣는다. 세이브 파일은 건드리지 않으므로 게임에서 저장해야 남는다.

- **목록**: 검색어가 없으면 내 팀 선수가, 있으면 모든 구단 선수가 나온다.
- **고칠 수 있는 값**
  - 현재·잠재 능력(1~200)
  - 능력치(1~20, 숨은 능력치 포함)
  - 왼발·오른발
  - 포지션 숙련 15자리(1~20)
- **고친 칸 표시**: 노란 테두리와 "원래 값"이 붙는다.
- **한꺼번에 넣기**: 여러 선수를 고쳐 두었다가 "게임에 반영"으로 한꺼번에 넣는다. 확인창을 거친다. 플러그인이 0.13.0보다 낮으면 온라인 게임인지 알 수 없어 확인창에 "네트워크 게임에서는 쓰지 마세요."를 더한다.
- **고친 값은 남는다**: 고친 값은 화면 밖 저장소(`lib/editorStore.ts`)에 있어 다른 화면에 갔다 와도 그대로다. "게임에 반영"으로 모두 들어간 선수나 "모두 버리기"·"이 선수 되돌리기"로 버린 선수만 비워지고, 다른 세이브를 적용하면 비운다. 에디터 메뉴에는 고친 선수 수가 표시된다(900px 이하에서는 점).
- **반영 결과**: 선수마다 들어간 항목과 들어가지 않은 항목(현재 능력, 잠재 능력, 포지션 숙련도, 능력치)을 보여 준다. 쓰다가 실패하면 플러그인이 되돌렸는지(되돌림에 실패해 값이 섞였을 수 있는지), 온라인 게임이라 막았는지도 알린다. 못 들어간 선수의 고친 값은 남아 있어 다시 반영하거나 버릴 수 있다.
- **검사**
  - 현재 능력이 잠재 능력보다 크면 넣지 않는다.
  - 넣은 뒤 다시 읽어 값이 같은지 확인한다.
- **조건**: 게임의 지금 값을 받은 선수만 고칠 수 있다. FM이 켜져 있고 같은 세이브여야 한다.

### 백업

게임이 세이브를 저장할 때마다 사본을 남긴다.

- 세이브마다 3개를 남기고 오래된 것부터 지운다. 개수는 3, 5, 10, 20, 30 가운데 고른다.
- 할 수 있는 일은 "지금 사본 남기기", 복원, 지우기다.
- 복원하기 전에 지금 세이브를 먼저 사본으로 남긴다. 이 사본에는 "복원 전 상태" 표시가 붙는다.
- 사본은 앱 데이터 폴더의 `backups`에 둔다.

### 설정

- **화면 색**: 어두운 블루(기본), 블랙
- **창 닫기**: 창을 닫아도 알림 영역에 남겨 둘지 고른다.
- **게임 안 직접 답변**
  - Claude API 키를 저장하거나 지운다.
  - AI 모델은 Sonnet 5.5(기본), Opus 5.5, Haiku 5.5 가운데 고른다.
  - 생각의 깊이를 고른다.
  - 누적 요청 수, 토큰 수, 비용 어림을 보여 준다.
- **역할 가중치**: 역할마다 능력치 가중치(0~5)를 고치고, 기본값으로 되돌린다.
- **데이터 위치**: 폴더를 열고 앱 버전을 본다.

### 여러 화면에 쓰이는 것

- **선수 정보 창**
  - 얼굴, 현재·잠재 능력과 성장 여지
  - 기본 정보, 능력치, 포지션별 소화 능력 그림, 숨은 능력치
  - 몸값·주급 아래에 금액의 출처: 게임이 보여 주는 금액인지, 세이브 값을 원화로 바꾼 것인지
- **선수 얼굴과 구단 엠블럼**
  - 사용자가 그래픽 폴더에 설치해 둔 페이스팩과 엠블럼 팩에서 찾는다.
  - 없으면 얼굴 자리에는 이름 머리글자를 쓰고 엠블럼은 비워 둔다.
  - 파일은 읽기만 하고 복사하지 않는다.

## 4. 게임 안에서 되는 것 (플러그인)

코드는 `plugin/`에 있다. 게임이 켜질 때 함께 올라온다.

### 직접 답변 칸

- **붙는 곳**
  - 기자회견, 면담, 팀 대화 화면의 선택지 아래
  - 경기 중에는 외침 메뉴가 떠 있을 때 화면 왼쪽 위. 처음엔 접혀 있다.
- **흐름**
  1. 하고 싶은 말을 적고 [말하기]를 누른다.
  2. 켜져 있는 앱이 그 말과 화면의 선택지를 Claude에 보낸다.
  3. Claude가 가장 가까운 선택지(경기 중에는 외침)와 상대의 반응을 돌려준다.
  4. 반응과 "적용할 선택지"가 칸에 뜬다.
  5. **사용자가 [반영하고 넘어가기]나 [외치기]를 눌러야** 게임에 적용된다. 적용 직전에 그 버튼의 글자가 그대로인지 다시 확인한다.
- **기다림 안내**
  - 앱이 45초 넘게 말을 가져가지 않으면 "앱을 켜면 쓸 수 있습니다"를 띄운다.
  - 90초 안에 답이 없으면 포기 문구를 띄운다.
- **입력 중**: 칸에 글을 쓰는 동안 게임 단축키를 잠시 끈다.
- **상대의 반응 대사**: 연출일 뿐 게임에 반영되지 않는다. 협상 장면에서는 AI가 합의한 것처럼 말하지 않게 막아 두었다.

### 경기 카드

앱 없이 플러그인만으로 게임 화면 오른쪽 위에 뜬다.

- **골 카드**
  - 보여 주는 것:
    - 득점자, 도움, 시간, 이번 경기 몇 호 골
    - 이 대회 시즌 득점과 통산 득점, 도움 선수의 시즌 도움
    - 대회 득점·도움 순위 5위까지, 사진
  - 멀티골·해트트릭·자책골은 제목이 따로 있다.
  - 9초 보인다. 순위표가 있으면 14초다.
  - 비디오 판독으로 페널티킥이 선언된 뒤 도움 없이 들어간 골은 "페널티킥"으로 표시한다.
- **최우수 선수 카드**: 경기가 끝나면 풀타임 보고서에서 평점이 가장 높은 선수를 고른다. 키패스·유효슈팅과 함께 15초 띄운다.

### 화면 기록

다른 화면을 지원하기 위한 조사용이다.

- 처음 보는 화면이 뜨거나 F10을 누르면 화면 구조와 그 화면이 쓰는 값을 `dumps` 폴더에 남긴다.
- 골 순간에도 몇 장 남긴다.
- 게임을 켤 때 오래된 기록을 지우고 최근 150개만 남긴다.

### 앱에 값을 알려 주는 창구

앱이 쓰는 창구:

| 무엇 | 하는 일 |
|---|---|
| 상태 | 플러그인 버전, 세이브를 불러왔는지, 감독·팀 이름, 내 팀 선수 이름 |
| 모든 선수의 지금 값 | 게임 메모리에서 능력치, 현재·잠재 능력, 포지션 숙련을 읽는다 |
| 선수 정보(한 번에 30명) | 몸값 범위, 주급, 계약 만료, 국적, 소속, 성별 |
| 이름(한 번에 60개) | 세이브에 이름이 없는 팀과 나라 |
| 구단 | 리그와 순위, 경기장과 관중, 시설, 유소년, 재정 |
| 선수단 건강 | 부상, 징계, 컨디션, 경기 감각, 사기, 평점, 최근 폼 |
| 직접 답변 | 적은 말 가져가기, 답 돌려주기, 외침 목록, 화면 구조 |
| 에디터 쓰기 | 선수 한 명의 값을 게임 메모리에 쓰고, 다시 읽은 값을 돌려준다 |

이 밖에 게임 구조를 조사하는 개발용 창구가 있다. 클래스와 값 목록, 메모리 찾기, 시험 카드 띄우기, 실험용 클릭이다. 모든 창구는 같은 암호가 있어야 쓸 수 있다.

### 에디터의 값 쓰기

- **기록 찾기**: 메모리에서 다음 순서로 적힌 기록을 찾는다. 숙련 15개, 능력치 54개, 현재·잠재 능력, 그리고 선수 고유 번호 두 번이다.
- **쓰기 전 검사**
  - 맞는 기록이 정확히 하나일 때만 쓴다.
  - 값 범위를 확인한다: 숙련 1~20, 능력치 1~100(화면의 1~20에 5를 곱한 값), 현재·잠재 능력 1~200.
  - 현재 능력이 잠재 능력 이하인지 확인한다.
- **쓴 뒤**: 다시 읽은 값을 앱이 보낸 값과 대조한다.

## 5. 점수 계산

네 단계가 같은 전술, 같은 자리를 기준으로 이어진다: 전술 분석 → 적합도 → 영입 추천 → 대시보드 판단. 단계마다 식은 따로 두지만, 어느 점수든 항목별로 풀어서 보여 줄 수 있게 했다. 식 전체는 [`scoring.md`](scoring.md)에, 코드는 `src/shared/`에 있다.

아래에서 σ는 그 역할 선수들 점수의 퍼짐(표준편차)이다. 화면에는 σ를 쓰지 않고 "상위권 평균보다 7점 높음"처럼 풀어 쓴다.

### ① 전술과 역할

- **포메이션**: 4-2-3-1, 4-3-3, 4-4-2, 3-5-2, 3-4-3의 5개다.
- **역할**: 14개다. 자리마다 하나를 고른다(굵은 것이 기본).

| 자리 | 고를 수 있는 역할 |
|---|---|
| 골키퍼(GK) | **골키퍼** |
| 중앙 수비(DC) | **센터백**, 볼 플레잉 센터백 |
| 측면 수비(DL, DR) | **풀백**, 윙백 |
| 윙백(WBL, WBR) | **윙백** |
| 수비형 미드필더(DM) | **수비형 미드필더**, 딥라잉 플레이메이커 |
| 중앙 미드필더(MC) | **박스 투 박스**, 딥라잉 플레이메이커, 플레이메이커 |
| 측면 미드필더(ML, MR) | **윙어** |
| 측면 공격(AML, AMR) | **인사이드 포워드**, 윙어 |
| 공격형 미드필더(AMC) | **공격형 미드필더**, 플레이메이커 |
| 최전방(ST) | **스트라이커**, 타깃맨 |

- **능력치 가중치**
  - 역할마다 핵심 능력치 6~7개에 4를, 도움 능력치 6~10개에 2를 준다. 나머지는 0이다.
  - 설정에서 능력치마다 0~5로 고칠 수 있다.

### ② 적합도와 주전 배정

- **적합도(0~100)**
  - 가중치로 매긴 능력치(1~20) 평균을 100점으로 바꾼 값이다.
  - 가중치의 60% 넘게 값을 알 때만 매긴다.
- **역할마다의 잣대**
  - 세이브 전체에서 그 역할의 자리 가운데 하나라도 숙련 15 이상인 남자 선수를 모아 평균과 σ를 구한다. 점수 차이는 이 σ로 잰다.
  - 기준 능력은 모든 역할이 같다. 내 1군 상위 11명의 현재 능력 중간값에서 10을 뺀 값이고, 최소 100이다.
  - 기준 능력 이상인 선수가 40명이 안 되는 역할은 기준을 10씩 낮춰 표본을 채운다. 그만큼 평균을 보정한다.
- **포지션 숙련 감점**: 숙련이 20보다 낮으면 적합도에서 σ의 배수를 뺀다.

| 숙련 | 1점 낮을 때마다 빼는 양 | 끝값 |
|---|---|---|
| 20 | 0 | 0 |
| 19~15 | 0.08σ | 15에서 0.40σ |
| 14~10 | 0.30σ | 10에서 1.90σ |
| 9 이하 | 0.50σ | 총점에 0.10~0.90을 곱하는 보정도 붙는다 |

- **주전 배정**
  - 자리 전체 합이 가장 좋은 조합을 고른다(헝가리안 방식).
  - 숙련 15 이상을 먼저 세운다.
  - 숙련 10~14 선수는 15 이상으로 채울 수 없는 자리에만 "임시 주전"으로 세운다.
  - 후보는 숙련 15 이상 가운데 자리마다 2명이다.
- **약한 자리**: 주전 평균보다 1.2σ 넘게 낮은 자리와, 주전이 없는 자리다.
- **자리 묶음**
  - 같은 포지션·같은 역할의 자리는 한 묶음이다.
  - 묶음에서 가장 약한 주전이 비교 기준이 된다. 이때 31세부터 해마다 1점씩 빠지는 나이 하락을 감안한다(골키퍼는 34세부터).
- **보강 필요도(0~100)**
  - 식: 45 × 주전 전력 + 25 × 후보 두께 + 15 × 주전 나이 + 15 × 주전 계약. 각 항목은 0~1의 위험이다.
  - 주전이 없으면 100이다.
  - 주전 나이: 31세(골키퍼 34세)에 0.4에서 시작해 해마다 0.15씩 오른다.
  - 주전 계약: 남은 기간이 1년 이내면 0.3에서 시작해 만료에 가까울수록 1로 오른다.
    - 임대로 온 주전은 원 소속과 맺은 계약이 아니라 임대가 끝나는 날로 센다. 세이브에 임대 만료일이 없어 오늘 이후 첫 6월 30일로 어림한다(추정, 화면에 "추정"이라고 적는다).
  - 나이·계약을 모르면 0.15로 둔다.
  - 23세 이하 후계자(주전과 2.5σ 안쪽)가 있으면 나이·계약 위험을 절반으로 줄인다.
  - 등급: 55 이상 시급, 30 이상 보강 권장, 12 이상 보통, 그 아래 충분이다.
  - 이유 문장은 5점 넘게 더한 항목 가운데 큰 두 가지로 쓴다. 주전 전력이 평균보다 조금 높은(0~1σ) 경우에는 "평균보다 조금 높지만 뛰어난 수준(평균+σ)에는 못 미칩니다"로 쓴다.

### ③ 영입 추천

- **비교 기준**: 그 자리 묶음의 가장 약한 주전("기준 주전")과 첫 후보다. 후보와 첫 후보에게도 주전과 같은 숙련 감점과 나이 하락을 뺀다. 나이 든 주전보다 첫 후보가 낫게 계산되면 그 첫 후보가 내년의 기준이 된다.
- **후보에서 뺀 선수**: 내 구단(2군·유스 포함), 내가 임대 보낸 선수, 이미 내 구단과 계약을 마친 무소속 선수, 여자 선수.
- **유형 자격**: 비교에는 0.25σ의 여유를 둔다.

| 유형 | 조건 |
|---|---|
| 즉시 전력 | 내년의 기준 주전만큼 맞고, 현재 능력이 기준 주전의 85% 이상 |
| 로테이션 자원 | 즉시 전력에는 못 미치지만 첫 후보만큼 맞음(기준 주전에서 1.5σ 안쪽). 현재 능력 85% 이상. 후보가 2명 미만인 자리는 창을 1.0σ까지 아래로 넓힌다 |
| 유망주 | 23세 이하. 잠재 능력이 현재보다 10 이상 높음. 다 컸을 때 0.5σ 넘게 나아지고 내년의 기준 주전에 닿을 만함. 현재 능력 문턱은 없음 |
| 자유 계약 | 소속이 없고 위 셋 가운데 하나에 드는 선수. 다른 구단과 계약을 마친 선수는 뺀다 |
| 전체 | 위 세 유형을 합친 것 |

- **성장 예측**
  - 다 컸을 때 늘어나는 적합도 = 역할의 성장 기울기 × 남은 성장 몫 × (잠재 − 현재)
  - 성장 기울기는 세이브에서 현재 능력 110~180 선수들로 잰 값이다(역할마다 다르다. 이 구간 표본이 40명 미만이거나 기울기가 0 이하이면 일반 기울기를 쓴다).
  - 남은 성장 몫은 세이브에서 나이별로 잰 표다. 17세 0.78, 18세 0.70, 20세 0.57, 22세 0.38, 24세 0.15, 26세부터 0이다. 골키퍼는 늦게 커서 따로 17세 0.73, 18세 0.72, 20세 0.58, 22세 0.46, 24세 0.28, 26세부터 0이다.
  - 성장을 쓰는 모든 곳(성숙 시 전력, 유망주 자격, 대시보드 임대 유망주)이 같은 함수를 쓴다. 한 시점의 세이브로 잰 값이라 유망주 탭 위에 불확실성을 한 줄로 적어 둔다.
- **추천 점수(0~100)**: 여섯 항목(각 0~1)의 가중합이다.

| 탭 | 즉시 전력 | 다 컸을 때 | 나이 | 비용 | 영입 난이도 | 신뢰성 |
|---|---|---|---|---|---|---|
| 전체 | 40 | 12 | 10 | 14 | 12 | 12 |
| 즉시 전력 | 50 | 4 | 10 | 14 | 10 | 12 |
| 로테이션 자원 | 36 | 6 | 8 | 20 | 16 | 14 |
| 유망주 | 12 | 40 | 10 | 14 | 12 | 12 |
| 자유 계약 | 44 | 10 | 12 | 10 | 8 | 16 |

- **항목별 내용**
  - 즉시 전력: 가중치가 그 자리의 보강 필요도에 따라 0.8~1.2배로 바뀐다. 합은 다시 100으로 맞춘다.
  - 비용: 주급(60%)과 몸값(40%)이 내 팀 수준에 견줘 얼마나 부담 없는지 본다. 계약이 짧으면 몸값 부담을 줄인다.
  - 영입 난이도: 남은 계약(40%), 구단 안 입지(40%), 체급(현재 능력 격차, 20%)으로 본다.
  - 신뢰성: 일관성, 부상 빈도, 큰 경기, 타고난 체력, 결단력, 비매너 플레이로 본다.
  - 나이: 전성기(필드 24~29세, 골키퍼 27~33세)에 가까울수록 높다. 유망주 탭은 어릴수록 높다.
- **그 밖의 규칙**
  - 모르는 값은 0.5(보통)로 둔다.
  - 숙련 10 미만이면 총점에 곱하는 보정이 붙는다.
- **등급**
  - 영입 현실성이 낮지 않은 후보만으로 순위를 매긴다.
  - 위 5%는 강력 추천, 20%까지는 추천, 50%까지는 고려, 나머지는 보류다.
  - 60점 미만은 보류다.
- **영입 현실성 낮음**
  - 소속이 있는 선수가 다음 가운데 하나에 들면 붙는다.
    - 주급이 내 팀 최고 주급의 1.3배 이상일 때
    - 구단의 핵심·중요 선수이면서 현재 능력이 기준 주전보다 25 이상 높을 때
    - 파는 구단의 체급(그 팀 남자 선수 현재 능력 상위 11명의 중간값)이 내 체급보다 3 넘게 낮지 않고, 그 팀의 핵심·중요·주전(골키퍼는 주전 골키퍼) 선수일 때. 임대 중인 선수는 원 소속 팀의 체급으로 본다
  - 소속이 없어도 다른 구단과 계약을 마친 선수(세이브에 주급 > 0, 만료일이 오늘 뒤인 계약 기록이 있음)에게 붙는다. 소속 칸에는 "구단명(입단 예정)"이라고 적는다.
  - 등급을 "고려"까지로 묶을 뿐, 점수와 순서는 그대로다.
- **자유 계약 선수의 주급**: 세이브에 없어서 대시보드 주급 모델의 기대 주급으로 어림한다. 주급 모델을 만들지 못한 리그에서는 모르는 것으로 두고 부담은 0.5다.
- **표의 "주전 대비"**: 후보의 비교 적합도에서 주전 기준(나이 하락을 뺀 값)을 뺀 값이다. 점수 풀이의 "주전보다 ○점 높습니다"와 같은 기준이다. 화면에 보이는 적합도끼리의 차이는 칸에 마우스를 올리면 보인다.
- **경고 문구**: 점수에는 넣지 않는다. 다음 세 경우에 붙는다.
  - 구단의 중요한 선수일 때
  - 현재 능력이 기준 주전보다 10 이상 높을 때
  - 계약이 4년 이상 남았을 때

### ④ 대시보드 판단

- **오늘의 브리핑**(최대 5줄)
  - 순위: 1위나 3위 이내는 좋음, 하위 3팀은 주의다.
  - 최근 경기: 3경기 미만이면 참고다. 무패에 절반 넘게 이겼으면 좋음, 절반 넘게 졌으면 위험이다.
  - 다음 경기: 날짜, 홈·원정, 상대를 적는다. 리그 경기면 상대의 순위와 승점도 적는다.
  - 보강: 가장 급한 자리의 등급을 적는다. 충분은 좋음, 보강 권장은 주의, 시급은 위험이다.
  - 계약: 1년 안에 끝나는 선수가 없으면 좋음, 3명 이상이면 주의다. 이미 끝난 선수는 따로 적는다. 임대로 온 선수는 "시즌 끝에 원 소속 팀으로 돌아간다"고 따로 적고, 1명 이상이면 좋음이 아니라 참고다.
- **연령 구조**: 21세 이하, 22~25세, 26~29세, 30세 이상으로 나눈다.
- **계약 만료**: 오늘부터 365일 이내와 365~730일로 나눈다. 임대로 온 선수는 원 소속 계약이 아니라 임대가 끝나는 날(추정)로 넣고 "임대 복귀" 표지를 단다.
- **주급 과다 의심**
  - 같은 리그 선수로 "능력과 나이로 본 기대 주급"을 구한다.
    - 식: ln 주급 = a + b × (현재 능력 − 145) + b2 × ((현재 능력 − 145) ÷ 10)² + 21세 미만 보정 + 30세 이상 보정. 제곱 항은 능력이 아주 높은 선수의 주급이 덜 오르는 것을 반영한다.
    - 내 리그 순위표의 팀이 8개 이상이고 선수가 30명 이상일 때만 만든다. 순위표를 못 읽는 리그에서는 다른 리그 선수로 대신하지 않고 "주급 기준을 세우지 못했습니다"라고 적는다(정리 후보의 주급 위험은 0.5).
    - 크게 벗어난 선수(3σ 밖)를 한 번 빼고 다시 맞춘다.
  - 기대보다 1σ 넘게 많이 받으면 의심, 1.5σ 넘으면 강한 의심이다.
  - 임대로 데려온 선수는 뺀다.
- **정리 후보**
  - 빼고 보는 선수:
    - 주전과, 자리마다 첫 후보
    - 현재 능력 상위 3명의 골키퍼
    - 임대로 데려온 선수
    - 임대 보내 키울 선수. 영입 후보의 유망주와 같은 자격(성장 여지가 크고, 다 컸을 때 그 자리 기준에 닿음)이다. 잠재 능력 순 5명을 따로 보여 준다. 성장 여지는 있어도 다 커서 못 미치는 선수는 정리 후보로 계산한다.
  - 식: 50 × 자리 위험 + 25 × 주급 위험 + 25 × 나이 위험
    - 자리 위험: 뛸 자리가 있으면 그 자리 첫 후보와의 차이로 잰다. 없으면 가장 잘 맞는 역할과 가장 약한 주전의 차이에 0.5σ를 더한다. 4번째 골키퍼부터는 최대다.
    - 주급 위험: 기대 주급보다 얼마나 많이 받는지로 잰다. 모르면 0.5다.
    - 나이 위험: 나이(24세 이하 0, 32세 이상 1)와 성장 정체를 6 대 4로 섞는다. 정체는 잠재가 현재보다 20 이상 높으면 0, 같으면 1이고, 28세 이상은 1로 본다.
  - 30점 이상인 선수 가운데 위에서 5명을 보여 준다.
- **영입 추천 카드**: 보강 필요도 1위 자리가 속한 묶음을 기준으로 즉시 전력 후보 3명을 고른다. 영입 현실성이 낮지 않은 후보 가운데 총점이 높은 순이고, 3명이 안 되면 나머지로 채워 "영입 현실성 낮음" 표지를 단다. 카드의 "주전과 적합도 ±N"은 표의 "주전 대비"와 같은 값이다.

### 수식 검토

- 점수 수식은 5회 넘게 검토하고 고치기로 했다. 5회차까지 반영했다(`scoring.md` 4장).
- 5회차(최종 독립 검토)에서 바뀐 것: 파는 구단의 체급을 영입 현실성에 넣음, 임대 영입 선수의 계약 끝, 임대 유망주를 영입 후보의 유망주 자격과 같게, 성장 기울기와 골키퍼 성장 몫, 다른 구단과 계약을 마친 무소속 선수, 표의 "주전 대비", 내가 임대 보낸 선수 제외, 로테이션 창, 필요도 이유 문장, 주급 모델 2차항, 순위표를 못 읽는 리그, 금액 표시.
- 채택하지 않은 것과 실제 세이브에서 확인한 값은 `scoring.md` 4장의 "5회차에서 바꾼 것"에 있다.

## 6. 어디서 무엇을 읽나

| 값 | 세이브 | 켜진 게임 |
|---|---|---|
| 이름, 생일·나이, 성별 | 읽음 | 성별을 더 알려 줌 |
| 국적 | 나라 번호만 읽음 | 나라 이름을 물어 채움 |
| 능력치 54개(숨은 것 포함), 현재·잠재 능력, 포지션 숙련 15개 | 읽음 | 지금 값으로 덮어씀 |
| 구단, 소속 팀, 계약(주급, 만료일, 입지), 임대 | 읽음 | 못 찾은 팀의 이름을 물어 채움 |
| 몸값 | 기준 몸값을 읽음 | 게임이 보여 주는 몸값 범위와 주급 |
| 경기 일정과 결과, 리그 순위표, 게임 날짜 | 읽음 | - |
| 구단 재정·시설·평판, 선수단 부상·사기·평점 | 못 읽음 | 물어 받음 |
| 이적 의사, 성격, 워크퍼밋, 키·체중, 게임 속 전술 | 못 읽음 | 받지 않음 |

- **세이브 형식**: 공개되어 있지 않아 26.3.2 세이브를 직접 분석해 읽는다. 게임이 업데이트되어 형식이 바뀌면 읽기가 실패할 수 있다.
- **사람 기록**
  - 이름 번호가 이름표에 실제로 있는 기록만 고른다.
  - 이 검사로 엉뚱한 이름과 나이로 읽히던 선수 3,277명을 바로잡았다.
  - 새로 만들어진 선수 19명은 이름이 비어 있을 수 있다.
- **이름 저장**: 게임에서 알아낸 나라·팀 이름은 앱 데이터 폴더의 `names`에 적어 둔다. FM이 꺼져 있어도 이 이름을 쓴다.
- **내 팀 찾기**: 게임이 알려 주는 내 팀 선수 이름으로 세이브에서 찾거나 사용자가 시작 화면에서 직접 골라, 한 번 정하면 세이브 파일 이름별로 기억한다. 게임이 꺼져 있어도 고를 수 있다. 게임이 켜져 있고 다른 구단을 알려 주면 게임이 이긴다.
- **세이브 형식 점검**: 읽은 직후 `src/main/saveCheck.ts`가 싼 불변식을 확인한다. 선수 수, 이름 없는 선수 몫, 임대 선수 수와 몫, 현재·잠재 능력의 범위와 크기 관계, 능력치·포지션 숙련의 범위, 뛸 포지션이 없는 선수 몫, 현재 능력 평균, 현재 능력과 능력치 평균의 상관, 나이다. 경계값은 점수 상수가 아니라 고정 시험 세이브(26.3.2, 선수 99,892명)의 실제 값에 여유를 둔 가드이고 `SAVE_GUARDS`에 근거를 적어 두었다. 걸리면 대시보드·스쿼드·영입 후보·선수 비교가 막히고(`WorldService.blocked`, 화면의 `SaveProblem`), 백업·설정·에디터는 그대로다.

## 7. 돈 표시

- **통화**: 세이브와 계산은 게임의 기준 통화인 파운드다. 화면에는 원화로 바꿔 보여 준다(1파운드 = 1,875원).
- **환율을 정한 방법**: 켜진 게임의 표시와 맞춰 정했다. 예를 들어 기준 통화 주급 4,000은 "750만 원"으로, 200,000은 "3.75억 원"으로 게임에 나온다.
- **적는 꼴**: 게임처럼 "1,130억 원", "46.9억 원", "3.75억 원", "960만 원"으로 적는다.
- **몸값 범위**: 표에서는 "120~180억 원"처럼 줄인다.

## 8. 화면 모양

자세한 값은 [`design.md`](design.md)에 있다.

- **바탕**: 밤 경기장의 어두운 남색이 기본이다. 설정에서 블랙(무채색)으로 바꾼다.
- **색의 뜻**
  - 색은 뜻이 있을 때만 쓴다. 초록은 좋음, 노랑은 주목(최고 구간, 고친 값), 주황은 주의, 빨강은 위험이다.
  - FM이 꺼져 있는 것은 평소 상태라 중립색으로 보인다.
- **능력치 칩**: 1~5 빨강, 6~10 회색, 11~15 초록, 16~20 노랑이다. 굵기도 함께 바뀌어 색만으로 뜻을 전하지 않는다.
- **글자**: 12.5px보다 작게 쓰지 않는다. 본문은 15px이고, 핵심 숫자는 크고 굵게 쓴다.
- **좁은 창**: 창 폭이 900px 이하이면 메뉴에 아이콘만 남는다.

## 9. 안전장치

- **세이브는 읽기만 한다.**
  - 세이브 폴더에 쓰는 것은 백업 복원뿐이다. 복원 전에 지금 세이브를 사본으로 남긴다.
  - 에디터는 세이브가 아니라 켜진 게임의 메모리를 고친다. 고친 세이브를 다시 묶어 보았지만 게임이 불러오지 않았기 때문이다.
- **플러그인 창구**
  - 이 PC 안 주소에서만 열린다.
  - 게임을 켤 때마다 새 암호를 만들고, 요청마다 확인한다.
  - 웹 페이지에서 온 요청은 거절한다.
  - 접속 정보는 `%LOCALAPPDATA%\FmBojwagwan\bridge.json`에 있다.
- **API 키**: Windows 계정에 묶인 암호화로 저장하고, 화면에는 돌려주지 않는다.
- **게임에 적용하는 것은 사용자가 누를 때만**
  - 직접 답변은 사용자가 버튼을 눌러야 적용된다.
  - 에디터는 확인창을 거친다.
- **플러그인 버전 확인**
  - 앱은 기능마다 필요한 플러그인 버전을 안다. 지금 값 읽기는 0.9.0, 몸값·주급·이름은 0.10.0, 구단·건강은 0.11.0이다.
  - 게임의 플러그인이 낮으면 그 기능은 쓰지 않고 FM을 다시 켜라고 안내한다.
- **스스로 멈춤**: 플러그인의 기능은 오류가 몇 번 나면 그 게임을 끌 때까지 스스로 멈춘다.

## 11. 아직 안 된 것과 알려진 한계

### 점수와 자료

- **FM26 역할 체계**(가장 큰 남은 일)
  - 앱의 역할은 FM24식 14개다. FM26은 역할이 공격 시와 수비 시로 나뉘고 이름도 다르다(1군에서 공격 시 40개, 수비 시 39개가 보였다).
  - 플러그인 0.12.0의 개발용 조회로 게임이 매긴 역할별 별점(20점 만점)을 선수마다 읽을 수 있다. 앱 화면에는 아직 쓰지 않는다.
- **역할 가중치**: 직접 정한 값이다. 1군 25명의 게임 별점과 대조했다(2026-11-28).
  - 전체 순위 상관은 0.75~0.80으로 같은 방향이다. 선수마다 앱 점수가 가장 높은 역할은 20명 모두 게임의 1위 역할에 들었다.
  - 윙어(0.38), 풀백·윙백·센터백(0.58~0.63)은 덜 맞는다.
  - 게임 별점은 현재 능력과도 비슷하게 맞고(0.77), 한 선수의 역할끼리는 차이가 작다. 그래서 가중치를 고칠 근거로는 아직 약하다.
- **포지션 숙련 감점 계수**
  - 순위를 가장 크게 흔드는 값인데 검증하지 않았다.
  - 게임에서 숙련 15와 20 선수의 평점을 비교해 확인할 계획이다.
- **점수에 못 넣는 것**
  - 이적 예산, 이적 의사, 평판, 워크퍼밋은 점수에 넣지 못한다.
  - 그래서 실제로는 못 데려올 선수가 위에 오를 수 있고, "영입 현실성 낮음" 표지로만 알린다.
  - 게임에 "매각 불가"로 나오는 선수를 반영하는 것도 아직이다.
- **전술**: 게임 속 전술(팀 지시, 역할)은 읽지 않는다. 앱에서 고른 전술을 쓴다.
- **어림한 상수**: 등급 경계, 성장 곡선 같은 상수는 실제 경기 결과로 맞춰 보지 않은 어림이다.
- **구단 체급 여유(3)**: 어림이다. 게임에서 즉시 전력 후보 상위 10명에게 제안을 넣어 협상이 시작되는 비율을 재서 맞춘다.
- **임대 끝 날짜**: 세이브에 임대 만료일이 없어 오늘 이후 첫 6월 30일로 어림한다. 완전 이적 옵션도 모른다. 플러그인으로 읽을 수 있는지는 FM을 켰을 때 읽기 전용으로 확인한다.
- **성장 예측**: 한 시점의 세이브로 잰 단면이다. 두 날짜의 세이브로 같은 선수의 변화를 재야 고칠 수 있다. 그때까지 유망주 탭 위에 불확실성을 적어 둔다.
- **근소한 배정**: 숙련 감점 계수를 바꾸면 측면 주전이 바뀔 만큼 근소한 자리가 있다. 알리지 않는다(계수를 게임에서 검증한 뒤 다시 본다).
- **워크퍼밋·전문가형**: 하부 리그를 맡거나 평점 자료가 생기면 다시 본다(지금은 영향이 없거나 판단 근거가 없다).

### 화면

- **버튼 이름**: 몇몇 버튼이 "홈"과 "시작"을 섞어 쓴다.
- **포지션 그림**: 리베로·중앙 수비·골키퍼 원이 조금 겹친다.
- **대시보드**: 계약 만료 카드에서 한 목록이 0명이면 안내 한 줄만 남아 칸이 비어 보인다.
- **알림 영역 아이콘**: 블랙 테마용이 없다.

### 게임과 플러그인

- **다시 시험할 것**: 게임 안 직접 답변과 에디터 "게임에 반영"을 플러그인 0.11.0에서 다시 시험하지 않았다.
- **유소년 단계**: 유소년 코칭·영입(2/5, 3/5)이 게임 화면의 단계와 같은지 모른다.
- **페널티킥**: 비디오 판독 뒤의 것만 가린다.
- **게임 업데이트**: 화면 요소 이름이 FM26 26.3 기준이라 업데이트 때 깨질 수 있다.
- **에디터 쓰기**: 숙련, 능력치, 현재 능력, 잠재 능력을 차례로 쓴다. 플러그인 0.13.0부터는 중간에 실패하면 앞에서 쓴 것을 되돌리고 그 결과를 알려 준다(앱은 선수·항목별로 보여 준다). 그보다 낮은 플러그인은 되돌리지 않는다.

### 코드를 읽다가 찾은 작은 보강거리

- **경로 검사**: 백업 사본 이름과 "폴더 열기" 경로를 앱 본체에서 한 번 더 검사하면 좋다. 지금은 화면이 주는 값을 그대로 쓴다.
- **오류 응답**: 플러그인 창구가 오류 때 오류 내용 전체를 돌려준다. 이 PC 안에서, 암호가 있어야 보이는 응답이다.
- **개발용 창구**: 일반 배포본에도 열려 있다. 값을 직접 부르는 것, 실험용 클릭이 여기에 든다. 암호가 있어야 쓸 수 있다.

# FM 보좌관

Football Manager 26 옆에 띄워 두는 Windows용 보조 앱과, 게임 안에서 도는 플러그인입니다.

- 세이브 파일은 읽기만 합니다.
- 에디터는 세이브가 아니라 켜져 있는 게임의 값을 바로 고칩니다.
- 백업 화면에서 복원할 때는 지금 세이브를 먼저 사본으로 남깁니다.

Sports Interactive, SEGA와 관계없는 개인 프로젝트입니다.

문서:

- [`docs/status.md`](docs/status.md): 지금 되는 것 전체와 남은 일
- [`docs/scoring.md`](docs/scoring.md): 점수 계산식(적합도, 보강 필요도, 영입 추천, 대시보드 판단)
- [`docs/design.md`](docs/design.md): 화면 디자인 규칙

## 쓰는 순서

1. 앱을 켜면 FM이 켜져 있는지부터 확인합니다. 게임 안 플러그인과 연결합니다.
2. **시작** 화면에서 쓸 세이브를 골라 **적용**합니다. 그 세이브의 모든 선수를 읽습니다(몇 초).
3. 그 자료로 대시보드, 스쿼드, 영입 후보, 선수 비교, 에디터를 씁니다. 시작 화면의 바로가기나 왼쪽 메뉴로 갑니다.

마지막으로 적용한 세이브는 다음에 앱을 켤 때 다시 적용되고, 그러면 대시보드로 바로 넘어갑니다.

선수의 이름·나이·구단은 세이브에서 읽습니다. 능력치는 두 곳 가운데 하나에서 가져옵니다. 어느 쪽인지는 화면 왼쪽 아래와 시작 화면에 나옵니다.

- **게임의 지금 값**: FM이 켜져 있고 같은 팀으로 들어가 있을 때 받아 씁니다.
- **세이브에 저장된 값**: 그 밖의 경우에 씁니다.

앱은 한 번에 하나만 뜹니다. 창을 닫아도 알림 영역에 남아 게임 안 직접 답변과 백업이 계속 동작합니다. 이 동작은 설정에서 끌 수 있습니다.

## 지금 되는 것

자세한 내용은 [`docs/status.md`](docs/status.md)에 있습니다.

- **대시보드**
  - 오늘의 브리핑
  - 보강이 가장 급한 자리의 영입 추천 3명
  - 계약 만료 예정
  - 구단 재정·시설과 선수단 건강(FM이 켜져 있을 때)
  - 선수단 현황과 연령 구조
  - 경기 센터와 리그 순위표
  - 정리 후보, 주급 과다 의심
- **스쿼드**
  - 내 팀 선수의 표: 정렬, 검색, 선수 정보 창
  - 전술판: 포메이션 5개와 자리마다 역할을 고르고, 적합도와 보강 필요도를 봅니다.
  - 뎁스 차트
  - 선수단 진단
- **영입 후보**
  - 세이브에 든 모든 구단의 선수를 고른 자리의 점수로 줄 세웁니다.
  - 내 팀 주전과 견주어 전체·즉시 전력·로테이션 자원·유망주·자유 계약으로 나눠 보여 줍니다.
  - 추천 등급(강력 추천·추천·고려·보류), 항목별 점수 풀이, 현재·잠재 능력도 함께 보입니다.
  - FM이 켜져 있으면 몸값·주급·계약 만료일·국적을 게임에 물어 표에 채웁니다.
- **선수 비교**: 내 팀 선수를 3명까지 레이더 그림과 능력치 표로 나란히 봅니다.
- **에디터**
  - 선수의 능력치(게임에 보이지 않는 것 포함), 포지션 숙련도, 현재·잠재 능력을 고칩니다.
  - 고친 값은 켜져 있는 게임에 바로 반영됩니다. 게임에서 저장해야 세이브에 남습니다.
- **백업**
  - 게임이 저장할 때마다 사본을 남깁니다. 세이브마다 최근 3개를 남기고, 개수는 3~30개 가운데 고릅니다.
  - 백업 화면에서 한 번에 복원합니다.
- **설정**: 화면 색(어두운 블루, 블랙), 창을 닫아도 남겨 두기, 직접 답변의 API 키·AI 모델·생각의 깊이, 역할 가중치.
- **게임 안 직접 답변**
  - 기자회견·면담·팀 대화와 경기 중에 하고 싶은 말을 적으면, Claude가 가장 가까운 선택지(경기 중에는 외침)를 고르고 상대의 반응을 보여 줍니다.
  - 아래 "게임 안 플러그인"을 참고하세요.
- **경기 카드**: 게임 화면 오른쪽 위에 잠깐 띄웁니다.
  - 골이 들어가면 득점자·도움·시간과 기록
  - 경기가 끝나면 평점이 가장 높은 선수

## 실행

Node.js 22.22 이상이 필요합니다.

```powershell
npm install
npm start
```

개발 중에는 `npm run dev`를 씁니다. 화면만 브라우저에서 볼 때는 `npm run web`을 씁니다(지어낸 선수들로 화면만 봄).

npm run typecheck

## 게임 안 플러그인 (개발 중)

`plugin/`은 FM26 안에서 도는 BepInEx 6 (IL2CPP) 플러그인입니다. "직접 답변" 칸을 붙이는 곳은 두 군데입니다.

- 기자회견·면담·팀 대화 화면의 선택지 아래
- 경기 중 외침 메뉴가 떠 있을 때 화면 왼쪽 위. 처음엔 접혀 있습니다.

쓰는 방법:

1. 칸에 하고 싶은 말을 적고 [말하기]를 누릅니다.
2. 켜져 있는 FM 보좌관 앱이 그 말과 화면의 선택지를 Claude에 보내, 가장 가까운 선택지와 상대의 반응을 받아 옵니다.
3. 반응과 "적용할 선택지"가 칸에 뜹니다. [반영하고 넘어가기](경기 중에는 [외치기])를 누르면 그 선택지가 게임에서 골라집니다. 누르기 직전에 그 버튼의 글자가 그대로인지 다시 확인합니다.

경기 카드는 앱 없이 플러그인만으로 뜹니다. 게임이 골 직후 화면 아래에 띄우는 알림과, 경기 뒤 풀타임 보고서의 선수 표를 읽어 만듭니다. 골 뒤에 게임이 "13경기에서 4득점을 달성했습니다" 같은 기록 알림을 띄우면 그 문장도 골 카드에 덧붙입니다.

카드에는 화면에 없는 기록도 붙습니다.

- **골 카드**: 득점자의 사진, 이 대회 이번 시즌 득점, 통산 득점, 도움 선수의 시즌 도움, 대회 득점·도움 순위 5위까지
- **최우수 선수 카드**: 사진, 키패스, 유효슈팅

이 값들은 게임 화면이 값을 받는 것과 같은 통로로 게임에 청해서 받습니다(`plugin/GameData.cs`). 사진은 게임의 그림 요소에 선수 번호로 된 주소를 주어 게임이 불러오게 합니다.

비디오 판독으로 페널티킥이 선언된 직후 도움 없이 들어간 골은 "페널티킥"으로 표시합니다. 판독 없이 주어진 페널티킥은 아직 가려내지 못합니다.

알아 둘 것:

- **API 키**
  - 앱에만 있습니다. Windows 계정에 묶인 암호화로 저장합니다.
  - 플러그인은 AI를 직접 부르지 않으므로 앱이 켜져 있어야 합니다.
- **플러그인 서버**
  - 이 PC 안에서만 닿는 주소에 작은 서버를 엽니다. 127.0.0.1을 쓰고, 열리지 않으면 localhost를 씁니다. 포트는 48526~48535 가운데 빈 곳입니다.
  - 요청마다 암호(토큰)를 확인하고, 웹 페이지에서 온 요청은 거절합니다.
  - 접속 정보와 기록은 `%LOCALAPPDATA%\FmBojwagwan`에 둡니다.
- **화면 기록**
  - 처음 보는 화면이 뜰 때와 골 순간에, 그때의 화면 구조와 그 화면이 쓰는 값들을 `dumps` 폴더에 남깁니다. 다른 화면을 지원하기 위한 조사용입니다.
  - 게임에서 F10을 누르면 지금 화면을 바로 남깁니다.
  - 게임을 켤 때 최근 150개만 남기고 지웁니다.
- **빌드**: .NET SDK 8과, BepInEx가 설치된 게임 폴더가 필요합니다. 게임과 BepInEx의 어셈블리는 그 폴더에서 바로 참조합니다.

```powershell
dotnet build plugin -c Release -p:Deploy=true
```

게임 폴더가 기본 위치가 아니면 `-p:GameDir="..."`를 붙입니다. 게임이 켜져 있으면 플러그인 파일이 잠겨 있습니다. 끈 뒤에 실행하면 다음 실행부터 적용됩니다.

## 알아 둘 점

- **구조를 참고한 곳**
  - 세이브 구조의 일부는 공개 해독기 [fmsave](https://github.com/rhiever/fmsave)(Randal S. Olson, MIT)의 구조 설명을 참고했습니다.
  - 해당하는 것은 능력치 뒤의 몸값 자리, 계약 기록, 국적 번호의 자리, 계약상 입지 값의 뜻, 경기 일정과 리그 순위표입니다.
  - 코드는 가져오지 않았습니다.
- **세이브 형식**
  - 공개돼 있지 않아 26.3.2 세이브를 직접 분석해 읽습니다. 게임이 업데이트되면 읽기가 실패할 수 있습니다.
  - 구조 설명은 `src/main/save/`에 있습니다.
    - `container.ts`: 꾸러미와 목차
    - `reader.ts`: 선수 기록
    - `world.ts`: 구단과 전체 선수
    - `contracts.ts`: 계약과 임대
    - `season.ts`, `fixtures.ts`, `leagueTable.ts`: 경기 일정과 리그 순위표
- **사람 기록 찾기**: 이름 번호가 이름표에 실제로 있는 기록만 고릅니다. 모양만 맞는 다른 자료를 잡아 엉뚱한 이름이나 나이로 읽히지 않게 하려는 것입니다.
- **보이는 값**: 영입 후보와 에디터는 게임이 감춰 두는 값(현재·잠재 능력, 일관성 등)과 스카우트하지 않은 선수의 능력치를 그대로 보여 줍니다. 스쿼드 표에는 게임 화면에 보이는 능력치만 넣습니다.
- **세이브에서 읽는 계약 값**
  - 영입 후보의 몸값·주급·계약 만료일·계약상 입지는 세이브에서 읽습니다.
  - 그래서 FM이 꺼져 있어도 보입니다. "계약이 1년 안에 끝나는 선수만" 같은 조건도 세이브의 모든 선수에 걸 수 있습니다.
- **돈**
  - 세이브의 금액은 게임의 기준 통화인 파운드이고, 계산도 파운드로 합니다.
  - 화면에는 원화로 바꿔 보여 줍니다(1파운드 = 1,875원, 켜진 게임의 표시와 맞춘 값).
  - FM이 켜져 있으면 표에 보이는 선수들의 금액을 게임이 보여 주는 그대로(스카우트 정도에 따른 범위) 받아 바꿔 보여 줍니다. 서른 명씩 묻습니다.
- **이름이 없는 것**
  - 세이브에는 번호만 있고 이름이 없는 것이 있습니다. 나라, 그리고 구단을 알아내지 못한 팀(선수 열에 하나쯤)입니다.
  - 이 이름들과 여자 팀인지는 FM이 켜져 있을 때 게임에 물어 앱 폴더의 `names`에 적어 둡니다(`plugin/PersonInfo.cs`, `src/main/names.ts`). 한 번 알아낸 것은 FM이 꺼져 있어도 씁니다.
  - 다 알아내기 전에는 국적이 비어 있고 여자 선수가 섞여 있을 수 있습니다.
- **얼굴과 엠블럼**
  - 사용자가 `문서\Sports Interactive\Football Manager 26\graphics`에 설치해 둔 페이스팩·엠블럼 팩에서 찾습니다. 파일은 읽기만 하고 복사하지 않습니다.
  - 없으면 얼굴 자리에 이름 머리글자를 씁니다.
- **게임의 오늘 날짜**: 세이브 꾸러미의 `game_info`에서 읽습니다. 나이 계산과 계약 고르기에 씁니다.
- **에디터가 세이브에 쓰지 않는 까닭**
  - 고친 세이브를 다시 묶어 보았지만 게임(26.3.2)이 "저장된 게임을 열 수 없습니다"라며 불러오지 않았습니다. 그래서 켜져 있는 게임의 메모리를 고칩니다(`plugin/LiveMemory.cs`).
  - 메모리 안의 선수 기록은 다음 자리로 찾습니다. 숙련도·능력치·현재 능력·잠재 능력이 모두 제 범위이고, 그 뒤에 그 선수의 고유 번호가 두 번 적혀 있습니다. 26.3.2에서 세이브의 선수 99,892명 중 99,888명을 찾았습니다.
  - 맞는 기록이 정확히 하나일 때만 쓰고, 쓴 뒤 다시 읽어 확인합니다.
- **선수 번호**
  - 세이브 파일과 켜진 게임의 메모리는 값의 순서가 다릅니다. 세이브에서 능력치 "앞"에 적힌 번호는 앞 사람의 것이고, 선수 자신의 번호는 능력치 "뒤"에 있습니다(`world.ts`의 `ownerUid`).
  - 이 번호가 게임이 쓰는 선수 번호와 같습니다.
- **플러그인 버전**
  - 앱은 기능마다 필요한 플러그인 버전을 알고 있습니다(`src/shared/game.ts`).
    - `NEEDED_PLUGIN`(0.9.0): 게임의 지금 값 읽기와 에디터
    - `MARKET_PLUGIN`(0.10.0): 몸값·주급·이름 묻기
    - `CLUB_PLUGIN`(0.11.0): 구단 재정·시설과 선수단 건강
  - 게임에 올라가 있는 플러그인이 낮으면 그 기능은 쓰지 않고, FM을 다시 켜 달라고 안내합니다.
  - 플러그인을 고치면 `plugin/Plugin.cs`의 `Version`과 함께 올립니다.
- **내 팀 찾기**
  - 켜져 있는 게임이 알려 주는 내 팀 선수 이름으로 세이브에서 찾고, 한 번 찾으면 기억합니다.
  - 그래서 세이브를 처음 적용할 때는 게임에서 그 세이브를 불러와 두어야 내 팀을 찾습니다.
